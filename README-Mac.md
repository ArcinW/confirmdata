# Mac 版使用说明

1. 解压 `美团1-100-mac.zip`。
2. 双击 `打开审核工具.html`，或双击 `启动工具.command`。
3. 工具会在浏览器里打开，不需要 Node.js。
4. 审核、保存、星标、备注都会写入当前浏览器的本地存储。
5. 全部审核完后，在网页首页点击 `导出 JSON`。

如果 Mac 提示无法打开 `启动工具.command`：

1. 打开“终端”。
2. 输入 `chmod +x `，注意最后有一个空格。
3. 把 `启动工具.command` 拖进终端窗口，按回车。
4. 再双击 `启动工具.command`。

说明：普通审核人员只需要用浏览器打开 `打开审核工具.html`。纯浏览器模式不访问外网，但如果清理浏览器网站数据，未导出的审核结果会丢失，因此每批审核完成后一定要导出 JSON。

`导入 JSON` 用于把已有审核结果重新载入浏览器，导入成功后会覆盖当前浏览器里的项目数据。支持直接导入项目数组，或包含 `projects` 数组的 JSON。

汇总审核结果时，把所有审核人员导出的 JSON 放到 `审核结果` 文件夹，然后双击 `汇总审核结果.command`。
