# Mac 版使用说明

1. 解压 `美团1-100-mac.zip`。
2. 双击 `启动工具.command`。
3. 工具会自动打开浏览器页面，地址是本机的 `127.0.0.1`。
4. 审核、保存、星标、备注都会写入当前工具包内的 `data/projects.json`。
5. 全部审核完后，在网页首页点击 `导出 JSON`。

如果 Mac 提示无法打开脚本：

1. 打开“终端”。
2. 输入 `chmod +x `，注意最后有一个空格。
3. 把 `启动工具.command` 拖进终端窗口，按回车。
4. 再双击 `启动工具.command`。

如果提示没有 Node.js，请先安装 Node.js 18 或更高版本：

https://nodejs.org/

汇总审核结果时，把所有审核人员导出的 JSON 放到 `审核结果` 文件夹，然后双击 `汇总审核结果.command`。
