# 采集确认单本地审核工具

这是一个本地网页审核工具。审核人员在自己电脑上运行工具，保存、星标、备注、审核完毕都会写入本地 `data/projects.json`。

## 审核人员使用

1. 双击 `启动工具.bat`。
2. 工具会自动打开浏览器页面。
3. 在首页点击项目名称进入详情页审核。
4. 审核过程中点击“保存修改”。
5. 审核完成点击“审核完毕”。
6. 全部审核完后，点击“导出 JSON”。

导出的 JSON 文件名会和工具包名称保持一致，例如：`美团1-100.json`。

## 工具包名称

工具包名称配置在：

```text
data/package.json
```

例如：

```json
{
  "packageName": "美团1-100"
}
```

后续分包时可改成 `美团101-200`、`美团201-300`。

## 汇总审核结果

1. 把所有审核人员导出的 JSON 放到 `审核结果` 文件夹。
2. 双击 `汇总审核结果.bat`。
3. 汇总文件会输出到 `汇总结果` 文件夹。

输出内容：

- `汇总结果.json`
- `汇总结果.csv`
- `重复项目记录.json`
- `读取失败记录.json`

重复项目会按 `updatedAt` 保留更新时间最新的一条，并在 `重复项目记录.json` 中记录。
