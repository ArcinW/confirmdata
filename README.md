# 采集确认单本地审核工具

这是一个本地网页审核工具。审核人员在自己电脑上用浏览器打开即可审核，保存、星标、备注、审核完毕都会先写入浏览器本地存储，最后通过“导出 JSON”交付审核结果。

## 审核人员使用

1. 双击 `打开审核工具.html`，或双击 `启动工具.bat`。
2. 工具会在浏览器里打开；不需要 Node.js、PowerShell、npm，也不需要输入 localhost。
3. 第一次打开时项目列表为空，点击“导入 JSON”并选择分配给自己的整批数据（例如 1-100）。
4. 导入成功后，在首页点击项目名称进入详情页审核。
5. 审核过程中点击“保存修改”，审核完成点击“审核完毕”。
6. 全部审核完后，点击“导出 JSON”。

导出的 JSON 文件名会和工具包名称保持一致，例如：`美团1-100.json`。导出内容始终是当前已导入批次的全部项目，例如导入了 1-100 共 100 条，即使只审核了 50 条，导出文件仍包含完整的 100 条；不会补入其他批次的数据。

说明：纯浏览器模式下，导入的整批项目以及后续保存、星标、备注、审核状态都会写入当前浏览器的本地存储。导入一次后，刷新页面、关闭后重新打开或重启电脑，都会自动恢复上次数据，不需要重复导入。如果清理浏览器网站数据，未导出的审核结果会丢失。因此每批审核完成后一定要点击“导出 JSON”。

“导入 JSON”会用新导入的完整项目数组覆盖当前浏览器里的项目数据。支持直接导入项目数组，或包含 `projects` 数组的 JSON。

`启动工具.bat` 只是帮你打开 `打开审核工具.html`，不会启动服务，也不会跳转到 `127.0.0.1`。

## 工具包名称

工具包名称配置在：

```text
data/package.json
```

例如：

```json
{
  "packageName": "美团1-100"
}
```

后续分包时可改成 `美团101-200`、`美团201-300`。

## 汇总审核结果

1. 把所有审核人员导出的 JSON 放到 `审核结果` 文件夹。
2. 双击 `汇总审核结果.bat`。
3. 汇总文件会输出到 `汇总结果` 文件夹。

输出内容：

- `汇总结果.json`
- `汇总结果.csv`
- `重复项目记录.json`
- `读取失败记录.json`

重复项目会按 `updatedAt` 保留更新时间最新的一条，并在 `重复项目记录.json` 中记录。
